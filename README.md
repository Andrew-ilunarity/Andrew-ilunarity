### 👨‍💻 About Me

Data Analyst with a strong engineering mindset, focused on **End-to-End data solutions** — from raw database extraction to business-grade dashboards.

- 📊 **Analytics & Storytelling:** Experienced in relational data modeling, finding anomalies in messy CRM exports, and translating complex data into core business metrics (Revenue, AOV, MoM) via Power BI.
- ⚡ **Engineering & Automation:** Author of high-throughput data processing tools (>1,000 files/sec with checksum validation) using Python (Polars) and SQL for automated Data Quality & ETL.
- 🛠 **Main Stack:** Python (Polars/Pandas), SQL, Power BI, GCP, Linux, Data Modeling.
- 🎯 **Focus:** Proactive, autonomous problem-solving, eliminating manual routine, and building scalable, production-ready data pipelines.

> *"Transforming raw, unstructured chaos into clean, high-performance data streams and actionable insights."*
